# 幽靈待辦

一份會鬧鬼的待辦清單。做完任務，小幽靈才吃得飽；放著不管，殭屍就會爬進來。

👉 線上試玩：https://ghost-todo.vercel.app

## 玩法

1. **新增任務**，可以選分類和期限。
2. **完成第一件任務**，蛋就會孵化成幼靈。
3. 寵物的**生命、飽足、心情**會隨時間下降，完成任務可以補回來。
4. 任務**逾期**就會生出一隻殭屍，在畫面下方爬行並持續吸血。
5. 生命歸零，寵物會變成**墓碑**，墓誌銘會點名你沒做完的任務。
6. 按「孵一顆新蛋」重新開始，過去的寵物都會留在**墓園**裡。

### 成長與進化

| 階段 | 條件 |
|---|---|
| 蛋 → 幼靈 | 完成第一件任務 |
| 幼靈 → 成靈 | 累計完成 7 件，且連續 3 天都有完成任務 |
| 成靈 → 進化 | 連續 10 天，且當成靈滿 24 小時 |

進化型態由最近 10 次完成紀錄決定：

- **夜貓子**：多數在 22:00–05:59 完成
- **早起鳥**：多數在 06:00–10:59 完成
- **學者**：多數是「讀書」或「工作」類任務
- **作祟鬼**：沒有明顯傾向

### 示範時鐘

頁面底部的「示範時鐘」可以快轉 1、6 或 24 小時，方便直接體驗逾期、殭屍和死亡的流程。「清除存檔」可以從頭開始。

## 開發

需要 Node.js 22 以上。

```bash
npm install
npm run dev        # 開發伺服器 http://localhost:5173
npm test           # 執行測試
npm run build      # 型別檢查並建置到 dist/
```

- 技術：Vite + React + TypeScript，純前端
- 存檔：瀏覽器的 localStorage，不會上傳到任何伺服器，換瀏覽器或清除網站資料就會不見
- 部署：推到 `main` 分支後，Vercel 會自動部署

遊戲規則都在 `src/game/engine.ts`，數值在 `src/game/constants.ts`。
